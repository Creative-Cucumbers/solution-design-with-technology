# 設計メモ（design.md のひな形）

作る前に、この3つだけ決めます。**ここに書いたものを、そのまま `/speckit-plan` に渡します。**

```
受け入れ条件 → spec.md → 【design.md ← いまここ】 → plan.md → tasks.md → 実装
                （AI）   （AIと相談して、人が決める）  （AIが詳細化／人がレビュー）
```

> [!IMPORTANT]
> **白紙から考えなくて構いません。** 進め方はこの3往復です。
>
> 1. AIに「**何を決めればいいか**」を質問させる
> 2. AIに「**案を3つ**」出させて、自分が選ぶ
> 3. AIに「**下書き**」を作らせて、**自分が仕上げる**
>
> プロンプトは [acceptance.md](./acceptance.md) の演習D-2にあります。

何を、どんな名前で持つか。あとから増える項目も、ここで見込んでおく。

## 仕上げの3点（AIの下書きを、自分のものにする）

下書きができたら、**この3つをやって初めて完成です。**

| | やること | できたか |
| --- | --- | --- |
| ① | **「要確認」を全部つぶす。** AIに聞いて、最後は自分で決めて書き換える | [ ] |
| ② | **1行ずつ、声に出して説明してみる。** 説明できない行は、言い換えてもらって書き直す | [ ] |
| ③ | **この紙を見ながら、次の質問に答えてみる**: 「写真は1件につき3枚まで」と言われたら、どこを直すか | [ ] |

> [!IMPORTANT]
> **③に答えられたら合格です。** 答えられないなら、つなぎ目がまだ書けていません。
> AIが書いた文章のままでも構いません。大事なのは、**全部の行を自分が説明できること**です。

## 5. この design.md を渡して、plan.md を作らせる

```
/speckit-plan design.md に書いたつなぎ目に従って設計してください。
データの形・画面の責務・呼び出し方は、design.md のとおりにしてください。
勝手に変えないでください。変えたほうがよい場合は、理由を書いて提案だけしてください。
```

出てきた `plan.md` は、**今度はちゃんと読みます。** 読むポイントは3つです。

- 上で決めたつなぎ目が、そのまま使われているか
- 勝手に足された前提がないか
- あとから変更が来たとき、どこを直すことになるか

# チーム編（4限・演習F-1で使う）

**チームで1つだけ作ります。** 全員がこれを手元に開いた状態で開発します。

| 足すことにした機能 | |

## T2. 契約（これが4限の本体）

**そのままコードに貼れる形で書きます。** 全員が、自分のファイルの先頭にこれをコピーします。

```js
// === チームの契約（1人で勝手に変えない） ===
//
// 落とし物 = {
//   id: string,
//   品名: string,
//   場所: string,
//   日付: string,          // 形式も決める 例 "2026-10-12"
//   写真: string[],
//   受取履歴: { 受取日時: string, 受取者: string }[]
// }
//
// 呼び出し方（この名前と引数は変えない）
//   追加(落とし物)            → なし
//   一覧取得(条件)            → 落とし物[]   条件 = { 場所?, 開始日?, 終了日? }
//   受取登録(id, 受取者)      → なし
```

> [!NOTE]
> **合意できたかの確かめ方**: 1人が契約を読み上げて、残りの人が「どんな画面と動きになるか」を言ってみる。
> **違う絵が出てきたら、まだ合意できていません。**

## T3. 分担（同じファイルを2人で触らない）

| ファイル | 担当 | 役割 | 他の人は |
| --- | --- | --- | --- |
| `index.html` | | 画面の骨組み。各部品の置き場所 | 触らない |
| `data.js` | | **契約の実装**。データの保持と、追加／一覧取得／受取登録 | 触らない |
| `post.js` | | 投稿フォーム。`追加()` を呼ぶ | 触らない |
| `list.js` | | 一覧表示と絞り込み。`一覧取得()` を呼ぶ | 触らない |

> `data.js` の担当を最初に決める。3人チームなら `post.js` と `list.js` を1人が持つか、`index.html` を `data.js` の担当が兼ねる。
