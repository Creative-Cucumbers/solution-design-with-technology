# グループワーク用タイマーの仕様（予備サンプル）

## 目的

3チームの作業時間を同時に管理する。演習Bの受け入れ確認を練習するための教材とする。

## 受け入れ条件

| ID | 条件 | 確認方法 |
| --- | --- | --- |
| AC1 | 3チーム分の時間を同時に計れる | 各チームを開始し、独立して時間が減ることを確認 |
| AC2 | 残り3分で表示の色が変わる | 181秒で開始し、180秒以下で黄色になることを確認 |
| AC3 | 一時停止と再開ができる | 停止中に減らず、再開でその残り時間から減ることを確認 |
| AC4 | 時間を超えたらマイナスで表示され続ける | 1秒で開始し、終了後も負の時間表示が続くことを確認 |
| AC5 | リセットは確認してから実行される | キャンセルで継続、承認で停止して設定時間に戻ることを確認 |
| AC6 | 時間が終わったら音で知らせる | 音声を有効にして開始し、0秒に達したとき1回鳴ることを確認 |

## このサンプルで決めた詳細

以下は講師の短い条件から必然的に決まるものではなく、実装のために具体化した仕様です。学生の仕様レビューでは、これらの判断が目的に合うかも検討してください。

- 設定時間は1〜86400秒の整数。初期値は300秒。開始後はリセットするまで変更できない。
- 色は3分超で白、残り3分以下で黄色、0秒以下で赤。状態の文字も表示する。
- 表示は分・秒単位。0秒を過ぎても停止せず、1秒以上超過するとマイナス表示になる。
- リセットは対象チームだけに作用し、設定時間に戻す。再開ではなく、新しい計測として開始できる。
- 終了音は1回の計測につき1回。超過後の再開では再通知しない。
- 音声は開始操作で準備する。「音を試す」で事前確認でき、音声を有効にできない場合はメッセージを出す。
- ログイン・保存・外部サービス・外部ライブラリは使わない。再読み込みすると初期状態に戻る。
- ブラウザを表示し、端末が起動している状態での使用を想定する。バックグラウンドやスリープ中の通知は保証しない。
