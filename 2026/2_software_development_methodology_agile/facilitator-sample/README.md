# 演習Bの予備サンプル（講師用）

**受け入れ条件を含むため、演習A終了後に配布してください。** スターターZIPには含めません。

生成待ちや利用制限で演習Bが進まない場合に、仕様レビューと受け入れ確認を続けるための教材です。AIの生成結果や学生の実装成果を示すものではありません。

## 配布・起動

1. 講師はこのフォルダを事前にUSB等へ保存する。
2. 必要な学生に、このフォルダの5ファイルをまとめて渡す。
3. 学生は自分たちの `spec.md` を保存してから、別フォルダのこのサンプルを開く。
4. `index.html` をブラウザで開く。サーバー・インストール・ネット接続は不要。
5. 「音を試す」で音量と出力先を確認する。

比較表には「サンプル使用」と記録し、自作の達成数とは区別します。提出物は自分たちで作成・レビューした仕様書です。

## ファイル

- [spec.md](./spec.md): 6つの受け入れ条件と、この実装で決めた詳細
- [plan.md](./plan.md): 実装計画
- [tasks.md](./tasks.md): 条件に対応するタスク
- [index.html](./index.html): 3チーム用タイマー

## 授業前の実機確認

以下は講師が教室のChrome / Edge / Safariと音声出力で確認する項目です。チェック欄は未確認の状態で残しています。

- [ ] **AC1**: 3チームを異なる時間で開始し、並行して減る。他チームの一時停止・リセットで影響されない。
- [ ] **AC2**: 181秒で開始し、残り3分になると黄色になる。時間超過後は赤色になる。
- [ ] **AC3**: 一時停止して数秒待っても残り時間が減らず、再開後はその残り時間から減る。
- [ ] **AC4**: 1秒で開始し、終了後も `-00:01`、`-00:02` と超過時間が増える。
- [ ] **AC5**: リセット確認でキャンセルすると継続し、承認すると停止して設定時間に戻る。他のタイマーは継続する。
- [ ] **AC6**: 「音を試す」で音が聞こえる。1秒で開始すると終了時に1回鳴り、超過中や超過後の再開では繰り返さない。リセット後に再度開始すると再び鳴る。
- [ ] 空欄・0・負数・小数の設定では開始できない。

ブラウザやOSによるバックグラウンド処理の抑制、端末のスリープ中の通知は保証しません。授業では画面を表示し、端末がスリープしない状態で使ってください。実機での確認結果をもとに使用可否を判断します。
