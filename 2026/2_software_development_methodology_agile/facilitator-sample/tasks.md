# タスク一覧（予備サンプル）

以下は仕様と実装作業の対応例です。実装は `index.html` に収録しています。授業環境での受け入れ確認は [README.md](./README.md) の未チェック項目を使ってください。

| ID | タスク | 対応する条件 |
| --- | --- | --- |
| T1 | 3チームの入力欄・時間表示・操作ボタンと、独立した計測状態を作る | AC1 |
| T2 | 残り時間から表示色と状態文を更新する | AC2 |
| T3 | 残り時間を保存する一時停止と、その値からの再開を作る | AC3 |
| T4 | 終了後も計測を続け、負の時間を表示する | AC4 |
| T5 | 確認ダイアログの承認後だけ、対象チームを設定時間に戻す | AC5 |
| T6 | 音声の準備・試聴・終了時の1回だけの通知を作る | AC6 |
| T7 | 3チームの並行操作、境界値、リセットの取消、音声を確認する | AC1〜AC6 |
