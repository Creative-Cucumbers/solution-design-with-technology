# Antigravity IDE のセットアップ手順

第2回の授業で使う **Antigravity IDE** を、自分のPCに入れて日本語で使えるようにする手順です。**授業の最初にみんなで一緒に進めます**ので、事前に終わらせておく必要はありません。うまくいかなくても、隣の人の画面を見ながら参加できるので心配しないでください。

> [!NOTE]
> **所要時間の目安**: ダウンロード5〜10分＋インストール3分＋日本語化3分

## 0. 授業に持ってくるもの

- [ ] ノートPC（**電源アダプタも忘れずに**。ダウンロードとAI利用でバッテリーを使います）
- [ ] **個人の Google アカウント**のメールアドレスとパスワード
  - 大学のアカウントでは使えない可能性があります。個人のGmailアカウントを用意してください
  - パスワードを忘れている人は、**授業前に一度ログインできるか確かめておいてください**（これだけはお願いします）
- [ ] ストレージの空き容量 **2GB以上**

## 1. 自分のPCの種類を確認する

ダウンロードするファイルを選ぶために、自分のPCの種類を知る必要があります。

### Windowsの人

1. キーボードの `Windows` キーを押しながら `I`（アイ）を押す → 設定が開く
2. **システム** → 一番下の **バージョン情報** を開く
3. **「システムの種類」** の欄を見る

| 表示 | あなたが選ぶもの |
| --- | --- |
| `64 ビット オペレーティング システム、x64 ベース プロセッサ` | **x64** |
| `64 ビット オペレーティング システム、ARM ベース プロセッサ` | **ARM64** |

ほとんどの人は **x64** です。

### Macの人

1. 画面左上の ** アップルマーク** をクリック
2. **このMacについて** を開く
3. **「チップ」** または **「プロセッサ」** の欄を見る

| 表示 | あなたが選ぶもの |
| --- | --- |
| `Apple M1` `Apple M2` `Apple M3` `Apple M4` など | **Apple Silicon** |
| `Intel Core i5` `Intel Core i7` など | **Intel** |

2021年以降に買ったMacはほぼ **Apple Silicon** です。

## 2. ダウンロードする（ここが一番間違えやすい）

次のリンクを開いてください。**「Antigravity IDE Standalone」の場所に直接飛びます。**

👉 **[https://antigravity.google/download#antigravity-ide](https://antigravity.google/download#antigravity-ide)**

> [!WARNING]
> このページには**似た名前のものが4つ**並んでいます。選ぶものを間違えないでください。
>
> | ページの表示 | 今回は |
> | --- | --- |
> | **Antigravity IDE Standalone** | ✅ **これを選ぶ** |
> | Antigravity 2.0 | ❌ 選ばない |
> | Antigravity CLI | ❌ 選ばない |
> | Antigravity SDK | ❌ 選ばない |
>
> 上のリンクで飛べなかった場合は、ページの一番上にある「Antigravity 2.0」を押してしまわないよう、**下にスクロールして「Antigravity IDE Standalone」の見出しを探してください。**

「Antigravity IDE Standalone」の中から、1で調べた自分のPCに合うものを選びます。

| OS | 選ぶもの | ダウンロードされるファイル |
| --- | --- | --- |
| Windows（x64） | Windows x64 | `.exe` ファイル |
| Windows（ARM64） | Windows ARM64 | `.exe` ファイル |
| Mac（Apple Silicon） | macOS Apple Silicon | `.dmg` ファイル |
| Mac（Intel） | macOS Intel | `.dmg` ファイル |

ファイルは数百MBあります。**ダウンロード中は待ち時間になるので、その間に講師が授業の話を進めます。**

> [!TIP]
> 教室の回線が混んで進まない場合は、講師がUSBメモリでインストーラを配ります。手が挙がっていれば声をかけてください。

## 3. インストールする

### Windowsの人

1. ダウンロードした `.exe` ファイルをダブルクリック
2. 警告画面が出た場合は、そのまま進めず、**公式サイトから入手したファイルか、表示されたアプリ名・発行元は正しいか**を確認する
   - 表示が手順書と違う場合や、判断できない場合は講師に確認してください
   - 警告の有無や表示内容は、Windowsの設定やファイルの状態によって異なります
3. 画面の指示に従って「次へ」「同意する」を進める
4. 最後に「完了」を押すと起動します

### Macの人

1. ダウンロードした `.dmg` ファイルをダブルクリック
2. 開いたウィンドウの中のアイコンを、**「Applications」（アプリケーション）フォルダにドラッグ**
3. アプリケーションフォルダから起動する
4. **「開発元が未確認」**などの理由で開けない場合は、まず講師に画面を見せ、公式サイトから入手した正しいファイルか確認する
   - 確認後、必要に応じて**システム設定 → プライバシーとセキュリティ → このまま開く**から許可します
   - 表示や操作はmacOSのバージョンによって異なります。[Apple公式の手順](https://support.apple.com/ja-jp/102445)も参照してください

## 4. Googleアカウントでログインする

起動すると、ログインを求められます。**個人のGoogleアカウント**でログインしてください。ブラウザが開いて認証される形式です。

- 大学のアカウント（`@kyoto-art.ac.jp` など）では使えない可能性があります
- 個人のGmailアカウントでログインしてください
- ログイン先のアカウントと求められている権限を確認して進めてください。判断できない場合は講師に確認してください

## 5. 日本語にする

最初は英語表示です。日本語にします。

1. キーボードで **`Ctrl` + `Shift` + `X`**（Macは **`Cmd` + `Shift` + `X`**）を押す
   → 左側に**拡張機能（Extensions）**の一覧が開きます
2. 検索欄に **`Japanese`** と入力
3. **Japanese Language Pack for Visual Studio Code**（作者が **Microsoft** のもの）を選び、**Install** を押す
4. 右下に **Restart**（再起動）のボタンが出たら押す
5. 再起動後、画面上部のメニューが **「ファイル」「編集」** などの日本語になっていれば成功

### 日本語にならない場合

1. **`Ctrl` + `Shift` + `P`**（Macは **`Cmd` + `Shift` + `P`**）を押す
2. `Configure Display Language` と入力して選ぶ
3. 一覧から **`日本語 (ja)`** を選ぶ
4. 再起動する

> [!NOTE]
> どうしても日本語にならない場合は、**英語のままでも授業は進められます**。この手順書に必要な操作は全部書いてあります。後で落ち着いてやりましょう。

## 6. 画面の見方とファイルの場所

Antigravity IDE は、画面が大きく3つに分かれています。

```
┌──────────────┬─────────────────────────┬──────────────────┐
│ ①エクスプローラー │ ②エディタ                 │ ③エージェント      │
│                │                         │  （チャット）      │
│ 開いたフォルダの │ ファイルの中身            │                  │
│ 中身が一覧で出る │ （コードが表示される）     │ AIに頼む場所      │
│                │                         │                  │
│ index.html     │                         │ ここに文章を入力   │
│ style.css      │                         │                  │
└──────────────┴─────────────────────────┴──────────────────┘
```

| | 名前 | 何をする場所か |
| --- | --- | --- |
| ① | エクスプローラー | **開いているフォルダの中身**が一覧表示される。AIが作ったファイルはここに増えていく |
| ② | エディタ | ファイルの中身（コード）が表示される。読めなくても問題ない |
| ③ | エージェント / チャット | **AIに頼みたいことを日本語で書く場所** |

> [!IMPORTANT]
> **①で開いているフォルダを作業場所として使います。** 「どこにできたか分からない」を防ぐために、必ず先にフォルダを開いてから頼んでください（次の7で用意します）。
>
> 実際の保存場所を確かめたいときは、①でファイルを右クリックして **「エクスプローラーで表示」**（Macは **「Finderで表示」**）を選ぶと、PC上の場所が開きます。

## 7. 演習で使うフォルダを用意する

この授業のファイルを置く場所を作ります。**後の回でも使うので、この形で作っておいてください。**

```
ソフトウェア開発演習/            ← この授業用のフォルダ（今後ずっと使う）
└── 第2回/                      ← 今日の回のフォルダ
    ├── vibe-coding/            ← 演習Aで使う（空のまま作る）
    └── starter-windows/        ← 演習Bで使う（配布ZIPを展開したもの）
```

> [!IMPORTANT]
> Antigravity IDE では、**「フォルダーを開く」で開いたフォルダ**が作業場所（ワークスペース）になります。
> 演習では **`vibe-coding` と `starter-windows` を、それぞれ直接開きます**。`第2回` を開いてはいけません（演習Bで使う設定が読み込まれません）。

### 7.1 授業用のフォルダを作る

置き場所は**デスクトップ**か**ドキュメント**、どちらでも構いません（デスクトップの方が見つけやすいです）。

**Windowsの人**

1. デスクトップの何もない所を**右クリック** → **新規作成** → **フォルダー**
2. 名前を **`ソフトウェア開発演習`** にして `Enter`
3. そのフォルダを開き、中で同じように右クリック → **新規作成** → **フォルダー** → 名前を **`第2回`**
4. `第2回` を開き、もう一度同じ手順で **`vibe-coding`** を作る

**Macの人**

1. デスクトップの何もない所を**右クリック**（またはトラックパッドを2本指でクリック） → **新規フォルダ**
2. 名前を **`ソフトウェア開発演習`** にして `Enter`
3. そのフォルダを開き、中で同じように右クリック → **新規フォルダ** → 名前を **`第2回`**
4. `第2回` を開き、もう一度同じ手順で **`vibe-coding`** を作る

> [!TIP]
> フォルダ名は**コピーして貼り付け**ると打ち間違いがありません。半角・全角は気にしなくて大丈夫です。

### 7.2 演習A用のフォルダを Antigravity IDE で開く

1. Antigravity IDE のメニューから **ファイル** → **フォルダーを開く**（英語なら `File` → `Open Folder`）
2. いま作った **`ソフトウェア開発演習/第2回/vibe-coding`** を選ぶ
3. ①エクスプローラーに **`VIBE-CODING`** と表示されればOK（中身は空です。授業前に[練習](./vibe-coding-first-steps.md)した人は、作ったフォルダが入っていても構いません）

> [!WARNING]
> 開くのは**フォルダ**です。ファイルではありません。また、開くのは **`vibe-coding`** です（`第2回` や `ソフトウェア開発演習` ではありません）。
> フォルダを開かずに始めると、AIが作ったものがどこに行ったか分からなくなります。

### 7.3 演習B用: スターターをダウンロードする

演習Bで使うファイル一式をダウンロードします。**自分のOSのものだけ**を落としてください。

| 自分のPC | ダウンロードリンク | サイズ |
| --- | --- | --- |
| **Windows** | 👉 **[starter-windows.zip をダウンロード](https://raw.githubusercontent.com/Creative-Cucumbers/solution-design-with-technology/main/2026/2_software_development_methodology_agile/starter-windows.zip)** | 約90KB |
| **Mac / Linux** | 👉 **[starter-mac.zip をダウンロード](https://raw.githubusercontent.com/Creative-Cucumbers/solution-design-with-technology/main/2026/2_software_development_methodology_agile/starter-mac.zip)** | 約92KB |

1. 自分のOSのリンクをクリックする（クリックするとダウンロードが始まります）
   - 始まらない場合は、**右クリック → 「名前を付けてリンク先を保存」**
2. ダウンロードしたZIPを、先ほど作った **`ソフトウェア開発演習/第2回`** フォルダに移動する
3. ZIPを**展開（解凍）**する
   - Windows: 右クリック → **すべて展開** → そのまま **展開** を押す
   - Mac: ダブルクリック
4. `第2回` の中が次のようになっていればOKです（Windowsの場合）

```
ソフトウェア開発演習/
└── 第2回/
    ├── vibe-coding/           ← 7.2で作った空フォルダ
    ├── starter-windows/       ← 展開してできたフォルダ（これを演習Bで開く）
    └── starter-windows.zip    ← 展開後は不要（消してもよい）
```

> [!WARNING]
> Windowsで「すべて展開」すると、`starter-windows/starter-windows/` のように**二重**になることがあります。
> その場合は、**中身（`.agents` などが入っている方）のフォルダを演習Bで開いてください。**

5. **演習Bのときに**、展開してできた **`starter-windows`（Macは `starter-mac`）フォルダ自体**を「フォルダーを開く」で開きます（今は開かなくてよい）

| 自分のPC | 演習Bで開くフォルダ |
| --- | --- |
| Windows | `ソフトウェア開発演習/第2回/starter-windows` |
| Mac / Linux | `ソフトウェア開発演習/第2回/starter-mac` |

> [!NOTE]
> 展開したフォルダを開いても、中身がほとんど見えません（設定ファイルが**隠しファイル**として入っているためです）。**空に見えても正常です。**

## 8. 完了チェック

授業の最初のセットアップは、ここまでできていればOKです。

- [ ] Antigravity IDE が起動した
- [ ] 個人のGoogleアカウントでログインできた
- [ ] （できれば）メニューが日本語になった
- [ ] `ソフトウェア開発演習/第2回/vibe-coding` を開いて、①エクスプローラーに `VIBE-CODING` と表示された
- [ ] 自分のOSのZIPをダウンロードして `第2回` の中で展開し、`starter-windows`（Macは `starter-mac`）ができた

**全部できなくても大丈夫です。** 演習は2人1組で進めます。自分のPCが動かないときは、ペアの画面を一緒に見て参加できます。

## 9. うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| ダウンロードが進まない・遅すぎる | 教室の回線が混んでいます。講師にUSBメモリを借りてください |
| ZIPのリンクを押しても何も起きない | リンクを**右クリック → 「名前を付けてリンク先を保存」**を選んでください |
| 展開したフォルダの中が空に見える | 正常です。設定ファイルが隠しファイルとして入っています |
| 演習Bで `/speckit-` と打ってもコマンドが出ない | ①開いたフォルダが `starter-windows`（Macは `starter-mac`）**そのもの**か確認（`第2回` を開いていると出ません） ②それでも出なければウィンドウを再読み込み、またはアプリを再起動 |
| どのファイルを選ぶのか分からなくなった | [antigravity.google/download#antigravity-ide](https://antigravity.google/download#antigravity-ide) を開き直して、**Antigravity IDE Standalone** から選んでください |
| 警告が出てインストールできない（Windows） | 公式サイトから入手したファイルか、アプリ名・発行元を確認します。判断できない場合は講師に画面を見せてください |
| 「開発元が未確認」で開けない（Mac） | 講師と入手元を確認後、必要に応じて「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を使います |
| 大学のアカウントでログインできない | 個人のGmailアカウントを使ってください |
| パスワードが分からない | 今日は隣の人の画面を一緒に見て進めてください。あとでSlackで相談しましょう |
| 拡張機能の画面が見つからない | ウィンドウを最大化してから `Ctrl`+`Shift`+`X` を押してください |
| 日本語にならない | 英語のままで進められます。[5](#5-日本語にする)の「日本語にならない場合」も試してみてください |
| インストールできない（管理者権限がない等） | ペアの相手の画面を一緒に見て進めます。講師に伝えてください |
