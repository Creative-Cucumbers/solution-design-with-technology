## 1. バイブコーディングとは

**AIに話しかけて、勢い（vibe）でソフトウェアを作るやり方**です。自分でコードを書かず、「こういうものを作って」と言葉で頼み、出てきたものを見て「ここを直して」と会話で修正していきます。

```
自分: 「電卓アプリを作って」
AI  : （コードを書く）→ 動くものができる
自分: 「ボタンを大きくして」
AI  : （直す）→ 直ったものができる
```

これだけです。**プログラミングの知識は要りません。**

授業では、このやり方の良いところと、これだけだと困るところを両方体験します。今日の目的は**手順に慣れておくこと**です。

## 2. 準備

[Antigravity IDE のセットアップ手順](./setup-antigravity-ide.md) を終えて、次の状態になっていればOKです。

- Antigravity IDE が起動していて、Googleアカウントでログインできている
- 空のフォルダ **`ソフトウェア開発演習/第2回/vibe-coding`** を「フォルダーを開く」で開いている

> [!WARNING]
> **開くのはフォルダです。ファイルではありません。** AIは「いま開いているフォルダ」の中にファイルを作ります。フォルダを開かずに始めると、作ったものがどこに行ったか分からなくなります。
> 画面の左側（エクスプローラー）に `VIBE-CODING` と出ていれば大丈夫です。

## 3. 作ってみる（5分）

> [!NOTE]
> **いつやるか**
> - **授業前・放課後など時間があるとき**: この電卓アプリを最後まで作ってみてください（5分）
> - **授業中（演習A）に開いた人**: お題はタイマーなので、この3はとばして **[4. ブラウザで開く](#4-ブラウザで開く)** と **[5. 直してみる](#5-直してみる)** の頼み方だけ真似してください

画面右側のエージェント（チャット）の入力欄に、**次の内容をそのままコピーして**送ってください。

```
電卓アプリを作成してください。
- html, css, javascriptだけで実現してください
- 上記を1つのファイルにしてください。
- 電卓アプリのフォルダを作成し、そこに配置してください。
```

> [!TIP]
> 3つの「-」の行は**条件**です。これを書いておくと、AIが勝手に別の技術を使ったり、ファイルをバラバラに作ったりしにくくなります。
> 授業では、こういう条件を先に書き出すことを **「仕様」** と呼んで詳しく扱います。

送ると、AIが自分で考えて動き始めます。ここからは**基本的に待つだけ**です。画面には次のようなことが表示されます。

- これから何をするかの説明（計画）
- 作ろうとしているフォルダとファイルの名前
- 書いたコードの中身

### 途中で止まって聞かれることがあります

AIは、ファイルを作ったりコマンドを実行したりする前に、**「やっていいですか?」と確認してくる**ことがあります。内容を見て、問題なければ許可してください（「Accept」「Allow」「実行」といった意味のボタンです）。

自分のために作った空フォルダの中の作業なので、基本的に許可して大丈夫です。

> [!IMPORTANT]
> ボタンの名前や画面の配置は、バージョンによって変わります。**「確認を求められたら許可する」**と覚えておけば十分です。

### できたものを確認する

画面左側のエクスプローラーを見てください。開いている `vibe-coding` フォルダの中に、**電卓アプリのフォルダができて、その中にファイルが1つ入っている**はずです。

```
VIBE-CODING
└── 電卓アプリ/          ← AIが作ったフォルダ
    └── index.html      ← 1つにまとめてもらったファイル（名前は違うこともあります）
```

**これが「AIが作ったファイルは、開いているフォルダの中にできる」ということです。** 頼んだとおりの場所にできているか、自分の目で確かめてください。

## 4. ブラウザで開く

作ったものは、**ブラウザで開かないと動きません。** これもAIに頼みます。

チャットに次の一文を送ってください。

```
作成した電卓アプリをブラウザで開いてください
```

AIがブラウザを立ち上げて、電卓を表示します。**数字のボタンを押して計算できれば成功です。**

> [!NOTE]
> AIが「ブラウザで開きました」と言っても画面が出てこないことがあります。そのときは次のように頼んでください。
>
> ```
> ブラウザで開けていないようです。開く方法を教えてください
> ```
>
> どうしても開かない場合は、自分で開くこともできます。エクスプローラーで `index.html` を**右クリック → 「エクスプローラーで表示」**（Macは「Finderで表示」）を選び、出てきたファイルを**ダブルクリック**してください。

> [!IMPORTANT]
> 真っ白な画面が出たり、ボタンを押しても何も起きないこともあります。**それも普通のことです。** 次の手順で直します。

## 5. 直してみる

**ここが一番大事な練習です。** 思い通りでない部分を、言葉で伝えて直してもらいます。

そのまま使える例文です。気になるものを送ってみてください。

```
ボタンをもっと大きくして、押しやすくしてください
```

```
背景を暗い色にして、文字を白にしてください
```

```
計算履歴が見えるようにしてください
```

```
1 + 2 = を押しても答えが表示されません。直してください
```

```
画面が真っ白で何も表示されません。原因を調べて直してください
```

直してもらったら、**もう一度ブラウザで確認**します（再読み込みすれば反映されます）。うまく反映されないときは、次のように頼んでください。

```
直した電卓アプリをもう一度ブラウザで開いてください
```

うまくいかないときは、**何が起きているかを日本語でそのまま伝える**のがコツです。「エラーが出た」より「**1 + 2 = を押しても 0 のままです**」の方が、AIは直しやすくなります。

2〜3回やり取りしてみてください。**これがバイブコーディングです。**

## 6. ここまでできればOK

次の4つができていれば、授業の準備は完了です。

- [ ] Antigravity にログインできた
- [ ] フォルダを開いて、AIに一言頼んでファイルができた
- [ ] できたものをブラウザで表示できた
- [ ] 「ここを直して」と伝えて、直った（または直そうとする様子を見た）

完璧な電卓ができている必要はありません。**途中で力尽きても、ここまでの流れを見ていれば大丈夫です。**

## 7. つまずいたとき

| 症状 | 対処 |
| --- | --- |
| どこに文章を入れるのか分からない | 画面右側のエージェント（チャット）の入力欄です。見つからない場合はウィンドウを最大化してください |
| AIが英語で返ってくる | 「日本語で説明してください」と送れば日本語になります |
| ブラウザが開かない | 「ブラウザで開けていないようです。開く方法を教えてください」と送る。または `index.html` を右クリック →「エクスプローラーで表示」→ ダブルクリック |
| 途中で止まったまま進まない | 確認を求められている可能性があります。画面にボタンが出ていないか探してください。無ければ「続けてください」と送ります |
| 「利用制限」「quota」などと言われた | 無料枠の上限です。時間をおくと回復します。その日は諦めて構いません（授業では2人1組なので大丈夫です） |
| エラーの英文が大量に出た | 全部コピーしてチャットに貼り、「このエラーを直してください」と送ればよいです。読む必要はありません |
| ファイルがどこにできたか分からない | 「作ったファイルの場所を教えてください」と送ります |
| 何度直しても直らない | 一度そこでやめて構いません。Slackで状況を教えてください |

**行き詰まったら、そこで終わりにしてください。** 授業の本題は「うまく作ること」ではありません。

## 8. 言葉の意味

| 言葉 | 意味 |
| --- | --- |
| **プロンプト** | AIに送る指示の文章のこと |
| **エージェント** | 自分で考えて、ファイルを作ったりコマンドを実行したりするAIのこと |
| **`index.html`** | ブラウザで開く入口のファイル。ダブルクリックで開く |
| **ターミナル** | コマンドを打つ黒い画面。AIが勝手に使うので、自分で打つ必要はない |
| **エクスプローラー** | 画面左側の、開いているフォルダの中身が並ぶ場所 |
| **承認 / Accept / Allow** | AIの作業を許可すること |
| **バイブコーディング** | AIに話しかけて勢いで作るやり方（今日やったこと） |
| **仕様駆動開発** | 先に「何を作るか」を書いてから作るやり方（授業で扱います） |

## 9. 注意すること

> [!CAUTION]
> - Antigravity IDE は無料のパブリックプレビューです。**利用回数に制限**があり、使いすぎると一時的に止まります（時間をおくと回復します）
> - 利用規約上、**入力した内容がGoogleに参照される可能性**があります。個人情報や、人に見せられない内容は入力しないでください
> - AIが出したものが正しいとは限りません。**動いているかどうかは自分の目で確かめてください**（授業ではこれを「受け入れ条件で確認する」と呼びます）
