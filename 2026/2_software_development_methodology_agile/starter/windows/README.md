# 演習用スターター（Windows 用）

**このフォルダ（配布ZIPを展開すると `starter-windows` という名前になります）を Antigravity IDE で開いて**ください（**ファイル → フォルダーを開く**）。1つ上のフォルダを開くとコマンドが読み込まれません。内部スクリプトは PowerShell 版です。

チャットで `/speckit-` と打ってコマンド一覧が出れば準備完了です。

## 授業での流れ

1. 受け入れ条件を自分の言葉で書く（ここは人間の仕事）
2. `/speckit-specify` — 仕様書を作る → **中身をレビューして直す**
3. `/speckit-plan` → `/speckit-tasks` — 計画とタスクに落とす
4. `/speckit-implement` — 実装する
5. 受け入れ条件を1つずつ確認する

作られた `spec.md` / `plan.md` / `tasks.md` は `specs/` の下に残ります。提出するのは、自分たちで作成・レビューした `spec.md` です。計画とタスクも振り返りに使えるので残してください。

詳細は [スターターの使い方](https://github.com/Creative-Cucumbers/solution-design-with-technology/blob/main/2026/2_software_development_methodology_agile/starter/README.md) を参照してください。
