## 進行上の仕掛け

- **受け入れ条件は10枚目で初めて提示します。** 演習A（9枚目）の時点では、スライドにも口頭にも出しません。
- **マシュマロチャレンジの2回目は予告しません。** ルール説明（40枚目）と1回目（43枚目）では回数に触れず、振り返り（52枚目）のあとに2回目（53枚目）が来ます。
- インストールの詳細手順はスライドに載せず、[セットアップ手順書](../setup-antigravity-ide.md)へのリンクにしています。投影するのは、そのとき操作することだけです。
- 講師向けの準備事項（材料の購入量、ペア編成、押したときの削り方など）はスライドに含めません。[講師向けメモ](../facilitator-notes.md)を参照してください。

## 表示・編集

`index.html`をブラウザで開きます。閲覧にインストールやネット接続は不要です（外部リンクを除く）。矢印キー／Spaceで移動、Shift+Spaceで戻る、Home／Endで先頭／末尾、Fで全画面、Hで操作バーを切り替えます。ページ番号入力とスマートフォンの左右スワイプにも対応しています。ブラウザから全60枚を印刷できます（1スライド＝1ページ）。

本文は`index.html`、デザインは`styles.css`、操作は`viewer.js`で編集できます。日本語文字と図形はHTML/CSS/SVGで組み、写真素材を画像生成しています。画像に文字を焼き込まず、表記の正確さと編集可能性を確保しています。

## PNGの再出力

Node.js、Playwright、SharpとChromiumが必要です。閲覧には不要です。

```bash
npm install --prefix /tmp/lecture-slide-tools playwright sharp
PLAYWRIGHT_BROWSERS_PATH=/tmp/lecture-slide-browsers /tmp/lecture-slide-tools/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/lecture-slide-tools/node_modules PLAYWRIGHT_BROWSERS_PATH=/tmp/lecture-slide-browsers node render.cjs
```

このディレクトリから実行すると、個別PNG、一覧PNG、`review.html`を更新し、文字の横溢れ、ページ操作、全画面表示、画面サイズへの追従、印刷時の全枚表示を検証します。枚数は`index.html`から自動で数えるため、スライドを足しても編集は不要です。Linuxでブラウザの依存ライブラリが不足する場合は、Playwrightのシステム依存ライブラリも必要です。
